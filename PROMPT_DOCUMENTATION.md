## Промпты коррекции

### Basic Correction Prompt

```text
Проанализируй текст и исправь все ошибки: орфографические, грамматические, пунктуационные.

Текст для исправления:
{input_text}

Исправленный текст:
```

**Принцип работы:**
- Простой и прямой подход
- Минимальные инструкции для модели
- Эффективен для базовых ошибок

**Использование:**
- Короткие тексты (< 500 символов)
- Простые грамматические ошибки
- Быстрая обработка

### Few-Shot Correction Prompt

```text
Проанализируй текст и исправь ошибки, изучив примеры:

Пример 1:
Оригинал: Власти игнорируют жалобы жителей на шум от стройки.
Исправлено: Власти игнорируют жалобы жителей на шум от стройки.

Пример 2:
Оригинал: Студенты успешно сдали экзамены и получили хорошие оценки.
Исправлено: Студенты успешно сдали экзамены и получили хорошие оценки.

Пример 3:
Оригинал: Компания планирует расширить производство и открыть новые филиалы.
Исправлено: Компания планирует расширить производство и открыть новые филиалы.

Теперь исправь текст:
Оригинал: {input_text}
Исправлено:
```

**Принцип работы:**
- Обучение на примерах
- Контекстуальное понимание
- Повышение качества для сложных случаев

**Использование:**
- Тексты средней сложности (500-1500 символов)
- Специфические грамматические конструкции
- Контекстуально зависимые ошибки

### Chain-of-Thought Correction Prompt

```text
Проанализируй текст пошагово и исправь ошибки:

Шаг 1: Найди орфографические ошибки
Текст: {input_text}
Орфографические ошибки:

Шаг 2: Проверь грамматические конструкции
Грамматические ошибки:

Шаг 3: Исправь пунктуацию
Пунктуационные ошибки:

Шаг 4: Улучши стиль и читаемость
Стилистические улучшения:

Шаг 5: Сформируй итоговый исправленный текст
Итоговый текст:
```

**Принцип работы:**
- Пошаговый анализ
- Систематический подход
- Максимальное качество

**Использование:**
- Сложные тексты (> 1500 символов)
- Множественные типы ошибок
- Высокие требования к качеству

## Промпты суммаризации

### Basic Summarization Prompt

```text
Создай краткое изложение основных мыслей текста:

Текст:
{input_text}

Краткое изложение:
```

**Принцип работы:**
- Простая инструкция
- Фокус на основных идеях
- Быстрая генерация

**Использование:**
- Новостные тексты
- Короткие документы
- Общие обзоры

### Few-Shot Summarization Prompt

```text
Изучи примеры кратких изложений и создай свое:

Пример 1:
Оригинал: Министерство здравоохранения объявило о новой кампании по вакцинации населения от гриппа. Кампания будет проходить в три этапа и охватит все регионы страны. Врачи рекомендуют привиться особенно пожилым людям и хронически больным.
Краткое изложение: Минздрав запускает трехэтапную кампанию вакцинации от гриппа по всей стране с приоритетом для пожилых и хронически больных.

Пример 2:
Оригинал: Ученые из МГУ разработали новый метод очистки воды от промышленных загрязнений. Метод использует нанотехнологии и позволяет удалять до 99% вредных веществ. Новая технология уже прошла успешные испытания на нескольких предприятиях.
Краткое изложение: Ученые МГУ создали нанотехнологический метод очистки воды, удаляющий 99% загрязнений, успешно протестированный на промышленных объектах.

Теперь создай изложение:
Оригинал: {input_text}
Краткое изложение:
```

**Принцип работы:**
- Обучение на примерах структуры
- Понимание соотношения длины
- Сохранение ключевой информации

**Использование:**
- Научные тексты
- Техническая документация
- Статьи с конкретной структурой

### Chain-of-Thought Summarization Prompt

```text
Проанализируй текст пошагово и создай краткое изложение:

Шаг 1: Определи главную тему текста
Тема:

Шаг 2: Найди ключевые факты и события
Ключевые факты:

Шаг 3: Выдели важные детали и цифры
Важные детали:

Шаг 4: Определи оптимальную длину изложения (25% от оригинала)
Целевая длина:

Шаг 5: Сформируй краткое изложение, сохраняя логику
Краткое изложение:
```

**Принцип работы:**
- Структурированный анализ
- Контроль длины
- Логическая связность

**Использование:**
- Сложные аналитические тексты
- Отчеты и исследования
- Многоаспектные документы

## Промпты оценки

### Correction Judge Prompt

```text
Оцени качество исправления текста по шкале от 1 до 10:

Оригинальный текст: {original_text}
Исправленный текст: {corrected_text}
Эталонный текст: {reference_text}

Критерии оценки:
1. Правильность исправления ошибок (0-3 балла)
2. Сохранение смысла (0-3 балла)  
3. Естественность языка (0-2 балла)
4. Полнота исправления (0-2 балла)

Анализ:
Исправленные ошибки:
Сохраненный смысл:
Естественность:
Полнота:

Итоговая оценка: __/10
Качество: [ПЛОХЕ/УДОВЛЕТВОРИТЕЛЬНОЕ/ХОРОШЕЕ/ОТЛИЧНОЕ]
Нуждается ли в повторной коррекции: [ДА/НЕТ]
```

### Summarization Judge Prompt

```text
Оцени качество краткого изложения по шкале от 1 до 10:

Оригинальный текст: {original_text}
Краткое изложение: {summary_text}
Эталонное изложение: {reference_summary}

Критерии оценки:
1. Точность передачи информации (0-3 балла)
2. Полнота охвата ключевых моментов (0-2 балла)
3. Логическая структура (0-2 балла)
4. Ясность и читаемость (0-2 балла)
5. Оптимальная длина (0-1 балл)

Анализ:
Точность:
Полнота:
Структура:
Ясность:
Длина:

Итоговая оценка: __/10
Качество: [ПЛОХЕ/УДОВЛЕТВОРИТЕЛЬНОЕ/ХОРОШЕЕ/ОТЛИЧНОЕ]
Нуждается ли в повторной суммаризации: [ДА/НЕТ]
```

## Адаптивные промпты

### Контекстно-зависимый промпт коррекции

```text
Проанализируй текст с учетом контекста и исправь ошибки:

Тип текста: {text_type} (новости/научный/официальный/разговорный)
Тема: {topic}
Целевая аудитория: {audience}
Уровень формальности: {formality_level}

Текст для исправления:
{input_text}

Особые требования:
- Сохранить стиль {text_type}
- Учитывать терминологию темы {topic}
- Адаптировать под аудиторию {audience}
- Соблюдать уровень формальности {formality_level}

Исправленный текст:
```

### Многоязыковой промпт коррекции

```text
Проанализируй текст на русском языке с учетом возможного влияния других языков:

Основной язык: русский
Обнаруженные влияния: {detected_influences} (английский/немецкий/французский)
Интерференции: {interferences}

Текст:
{input_text}

Коррекция с учетом языковой интерференции:
```

### Специализированный промпт научной коррекции

```text
Выполни научную редактуру текста с сохранением терминологии:

Ключевые термины: {key_terms}
Стиль: научный/академический

Текст:
{input_text}

```

```
Исследователи Стэнфордского университета разработали алгоритм машинного обучения, анализирующий медицинские изображения с 95% точностью, который показал лучшие результаты в клинических испытаниях.
```

**Chain-of-Thought результат:**
```
Ученые Стэнфорда создали алгоритм машинного обучения на основе глубоких нейронных сетей, который анализирует медицинские изображения с точностью 95% и превосходит традиционные методы диагностики в клинических испытаниях.
```

## Оптимизация промптов

### Техники оптимизации

1. **Температурная настройка**
   - Low temperature (0.3): для точных исправлений
   - Medium temperature (0.7): для баланса точности и креативности
   - High temperature (1.0): для сложных случаев

2. **Длина контекста**
   - Оптимальная длина: 2000-4000 токенов
   - Превышение ведет к деградации качества

3. **Структурирование**
   - Четкие разделы и подзаголовки
   - Последовательные инструкции
   - Конкретные примеры

### A/B тестирование промптов

```python
def test_prompt_variants(text, reference, prompt_variants):
    results = {}
    for variant_name, prompt in prompt_variants.items():
        result = apply_prompt(text, prompt)
        metrics = calculate_metrics(result, reference)
        results[variant_name] = {
            'result': result,
            'metrics': metrics
        }
    
    # Выбор лучшего варианта
    best_variant = max(results, key=lambda x: results[x]['metrics']['overall_score'])
    return best_variant, results[best_variant]
```
