# Как работает умная система обработки текстов

## Введение

Представь, что у тебя есть много разных текстов на русском языке - статьи, документы, рассказы. И тебе нужно сделать с ними две вещи:

1. **Исправить ошибки** - сделать тексты более грамотными
2. **Сделать краткое содержание** - выделить главную мысль

Это очень похожее на то, что ты делаешь в школе, когда учитель просит исправить диктант или написать краткое пересказ прочитанного.

## Что делает наша система?

Наша система - это как умный помощник, который умеет работать с текстами. Она состоит из нескольких частей:

### 🤖 Искусственный интеллект

В центре всего стоит большая языковая модель - как очень умный робот, который знает русский язык. Она называется **Gemma-3-12b-it**.

Представь, что этот робот прочитал миллионы книг, статей и документов. Теперь он может:
- Понимать смысл текстов
- Находить ошибки
- Пересказывать содержание своими словами
- Оценивать качество текстов

### 📋 Два главных процесса

Система выполняет два основных действия:

#### 1. Коррекция текста
```
Исходный текст: "Вчера я пошол в магизин и купил хлеБ"
Исправленный текст: "Вчера я пошёл в магазин и купил хлеб"
```

#### 2. Суммаризация (краткое изложение)
```
Длинный текст: "Вчера я пошёл в магазин. Там было много людей. Я купил хлеб, молоко и яблоки. Потом я пошёл домой и приготовил ужин."
Краткое содержание: "Автор пошёл в магазин, где купил продукты, а затем приготовил ужин."
```

## Как устроена система изнутри?

### 🏗️ Основные компоненты

#### 1. **Оркестратор** - главный дирижёр
Это как дирижёр в оркестре. Он руководит всем процессом:
- Получает текст
- Решает, что делать дальше
- Отправляет текст другим частям системы
- Собирает результаты вместе

#### 2. **Агенты-исполнители** - специалисты
Это как разные специалисты, каждый умеет что-то одно очень хорошо:

**Корректор-агент**:
- Знает правила русского языка
- Находит орфографические ошибки
- Исправляет пунктуацию
- Улучшает стиль

**Суммаризатор-агент**:
- Понимает главную мысль текста
- Выделяет ключевые моменты
- Пишет краткое содержание
- Сохраняет основной смысл

#### 3. **Метрики** - система оценок
Это как оценки в школе. После работы система ставит себе оценки:

**Для коррекции:**
- **WER** - сколько ошибок осталось (чем меньше, тем лучше)
- **LevRating** - насколько похож исправленный текст на правильный (чем больше, тем лучше)
- **Perplexity** - насколько текст стал понятнее (чем меньше, тем лучше)

**Для суммаризации:**
- **G-Eval** - оценка качества краткого содержания (от 0 до 1)
- **METEOR** - насколько хорошо пересказан смысл (от 0 до 1)
- **LLM-Judge** - оценка другого искусственного интеллекта (от 1 до 10)
- **BertScore** - насколько похоже на эталон (от 0 до 1)

### 🔄 Как всё работает вместе

Представь конвейер на заводе:

```
Текст → Оркестратор → Корректор → Проверка качества → Суммаризатор → Проверка качества → Результат
```

**Шаг 1:** Оркестратор получает текст и решает: "Сначала исправим ошибки!"

**Шаг 2:** Корректор исправляет текст, как учитель проверяет диктант

**Шаг 3:** Система проверяет, насколько хорошо исправлен текст (ставит оценки)

**Шаг 4:** Суммаризатор читает исправленный текст и делает краткое содержание

**Шаг 5:** Система проверяет, насколько хорошо получилось краткое содержание

**Шаг 6:** Оркестратор собирает всё вместе и показывает результат

## 🧠 Умные приёмы системы

### Few-Shot (примеры для обучения)
Система использует примеры, как ты учишься по готовым задачам:

```
Пример 1:
"Я пошол в школ" → "Я пошёл в школу"

Пример 2:  
"У меня есть каша" → "У меня есть кошка"

Теперь исправь: "Я люблю играт в футбол"
```

### Chain-of-Thought (цепочка рассуждений)
Система думает по шагам, как ты решаешь сложную задачу:

```
1. Прочитаю текст внимательно
2. Найду все ошибки
3. Подумаю, как их правильно написать
4. Проверю, что смысл не изменился
5. Запишу исправленный текст
```

### Ансамбль (коллективное решение)
Система использует несколько "мнений" разных агентов, как когда советуешься с друзьями:

```
Агент 1: "Я думаю, что тут ошибка в слове 'пошол'"
Агент 2: "Согласен, нужно 'пошёл'"
Агент 3: "Точно, по правилам русского языка пишется через 'ё'"

Итог: "пошёл"
```

## 📊 Как система оценивает свою работу

### Система оценок как в школе

Каждый处理 получает оценки по разным предметам:

**Коррекция (исправление ошибок):**
- Русский язык (WER) - оценка от 0 до 100%
- Грамотность (LevRating) - оценка от 0 до 1
- Понятность (Perplexity) - оценка от 0 до ∞

**Суммаризация (краткое изложение):**
- Понимание смысла (G-Eval) - оценка от 0 до 1
- Точность пересказа (METEOR) - оценка от 0 до 1
- Качество изложения (LLM-Judge) - оценка от 1 до 10
- Соответствие оригиналу (BertScore) - оценка от 0 до 1

### Как выставляется итоговая оценка

Система считает средний балл, как в конце четверти:

```
Итоговая оценка = (G-Eval × 25%) + (METEOR × 40%) + (LLM-Judge × 20%) + (BertScore × 25%)
```

- **Видеть все обработанные тексты** - как список учеников в классе

## 🎯 Практические примеры

### Пример 1: Исправление диктанта

**Исходный текст:**
```
Мой друг пошол в парк вчера. Там было много цветев и деревьев. Мы играли в футбол и веселись. Потом мы пошли домой и пили чай с печенье.
```

**Что делает система:**
1. **Находит ошибки:** пошол → пошёл, цветев → цветов, веселись → веселились, печенье → печеньем
2. **Исправляет текст:**
```
Мой друг пошёл в парк вчера. Там было много цветов и деревьев. Мы играли в футбол и веселились. Потом мы пошли домой и пили чай с печеньем.
```
3. **Ставит оценки:**
   - WER: 0.15 (15% ошибок)
   - LevRating: 0.92 (очень хорошо)
   - Perplexity: 8.5 (понятный текст)

### Пример 2: Краткое изложение статьи

**Длинная статья:**
```
Вчера в нашем городе состоялось важное событие - открытие новой библиотеки. На открытие пришли многие жители города, включая мэра и известных писателей. Библиотека расположена в современном здании в центре города. В ней есть три зала: для взрослых, для подростков и для детей. В библиотеке установлено 50 компьютеров с доступом в интернет. Книги в библиотеке отсортированы по жанрам: художественная литература, научная литература, справочники и периодика. Первые посетители уже успели оценить удобство помещения и богатый выбор книг. Директор библиотеки обещает проводить интересные мероприятия для читателей.
```

**Краткое содержание от системы:**
```
В городе открылась новая современная библиотека с тремя залами и 50 компьютерами. В ней представлена богатая коллекция книг разных жанров, а директор обещает проводить интересные мероприятия для посетителей.
```

**Оценки качества:**
- G-Eval: 0.89 (отлично)
- METEOR: 0.76 (хорошо)
- LLM-Judge: 8.5 (отлично)
- BertScore: 0.91 (отлично)
