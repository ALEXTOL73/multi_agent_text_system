# 🚀 Инструкция по использованию оптимизаций

## ✅ Реализованные улучшения

### 1. 🧠 Кэширование LLM запросов

#### Что это?
Система теперь запоминает результаты одинаковых запросов к LM Studio и возвращает их из кэша вместо повторного обращения к модели.

#### Как работает?
- Создается уникальный ключ на основе промпта, температуры, максимального количества токенов и системного промпта
- Результат сохраняется в кэш на 100 запросов (можно настроить)
- При повторном запросе с теми же параметрами результат возвращается мгновенно

#### Включение/выключение:
```python
# В src/utils/lm_studio_client.py при создании клиента:
client = LMStudioClient(
    cache_enabled=True,      # Включить кэш
    cache_size=100          # Размер кэша
)
```

#### Проверка статистики:
```python
# Получение статистики кэша
stats = client.get_cache_stats()
print(f"Hit rate: {stats['hit_rate']:.2%}")
print(f"Cache hits: {stats['cache_hits']}")
print(f"Cache misses: {stats['cache_misses']}")
```

### 2. ⚡ Асинхронная обработка файлов

#### Что это?
Система теперь может обрабатывать несколько файлов одновременно вместо последовательной обработки одного за другим.

#### Как работает?
- Использует `asyncio.Semaphore` для ограничения количества одновременно обрабатываемых файлов
- Каждый файл обрабатывается в отдельной асинхронной задаче
- Прогресс отслеживается в реальном времени

#### Настройка в main.py:
```python
# В main.py:
use_async_processing = True          # Включить асинхронную обработку
max_concurrent_files = 3            # Максимум файлов одновременно
```

#### Параметры:
- `max_concurrent_files`: от 1 до 5 файлов одновременно
- Рекомендуемое значение: 3 для баланса производительности и нагрузки

## 🐛 Устранение проблем

### Проблема: Нет ускорения от кэша
**Решение:**
- Проверьте что параметры запроса идентичны
- Убедитесь что `cache_enabled=True`
- Проверьте статистику кэша

### Проблема: Ошибки при асинхронной обработке
**Решение:**
- Уменьшите `max_concurrent_files` до 2
- Проверьте что LM Studio может обрабатывать несколько запросов
- Увеличьте `REQUEST_TIMEOUT` в config.py

### Проблема: Высокая нагрузка на систему
**Решение:**
- Уменьшите `max_concurrent_files`
- Уменьшите `cache_size`
- Отключите одну из оптимизаций
