## 🚀 Быстрый старт

### Для технических специалистов

1. **Установка и настройка**
   ```bash
   # Установка зависимостей
   pip install -r requirements.txt
   
   # Запуск LM Studio
   # Настроить модель gemma-3-12b-it на порту 1234
   
   # Запуск системы
   python main.py
   ```

2. **Основные компоненты**
   - [`main.py`](./main.py) - точка входа
   - [`src/orchestrator.py`](./src/orchestrator.py) - оркестратор
   - [`src/agents/`](./src/agents/) - агенты системы
   - [`config.py`](./config.py) - конфигурация

3. **Мониторинг**
   - Веб-интерфейс: http://127.0.0.1:5000
   - Логи: `logs/`
   - Метрики: `data/Table_metrics_ДДММГГ.xlsx`

### Для разработчиков

1. **Структура проекта**
   ```
   src/
   ├── agents/          # Агенты системы
   ├── utils/           # Утилиты и хелперы
   ├── learning/        # Модуль обучения
   ├── metrics/         # Расчет метрик
   └── orchestrator.py  # Оркестратор
   ```

2. **Добавление новых агентов**
   - Наследоваться от `BaseAgent`
   - Реализовать метод `execute()`
   - Добавить в конфигурацию

3. **Тестирование**
   ```bash
   # Запуск тестов
   python -m pytest tests/
   
   # Тест конкретного компонента
   python -m pytest tests/test_agents.py
   ```

## 📖 Детальное описание

### Агенты коррекции
1. **CorrectionPromptGenerator** - генерация промптов
2. **CorrectorEnsemble** - ансамбль корректоров
3. **CorrectorAggregator** - агрегация результатов
4. **CorrectionJudge** - оценка качества

### Агенты суммаризации
1. **SummarizationPromptGenerator** - генерация промптов
2. **SummarizerEnsemble** - ансамбль суммаризаторов
3. **SummarizerAggregator** - агрегация результатов
4. **SummarizationJudge** - оценка качества

### Метрики качества
- **WER (Word Error Rate)** - точность коррекции
- **LevRating** - качество на основе Левенштейна
- **Perplexity** - сложность текста
- **G-Eval** - оценка с помощью GPT
- **LLM-Judge** - оценка языковой моделью
- **METEOR** - метрика суммаризации
- **BERTScore** - семантическое сходство
